## 知乎文案

（发"想法"或自问自答"有哪些好用的健身计划工具"）

作为一个既要上班又要健身的人，我发现市面上的健身 App 有两个极端：要么计划是死模板，所有人练一样的；要么功能堆到要先看教程。所以我花了几个周末自己写了一个：**FitUp —— 一个根据你的个人情况自动生成一周训练计划的网站**。

核心逻辑是一个规则引擎：根据你的目标（增肌/减脂/塑形/保持）、可用器械、每周训练频率、运动专项、伤病情况，生成差异化的一周计划；每周结束后你反馈完成度、难度感受、酸痛、睡眠，系统据此动态调整下周强度，实现渐进超负荷。另外还有每日打卡、体重体脂趋势图、按体重目标计算热量和蛋白质摄入。

技术上很朴素：React + Supabase，邮箱验证码免密登录，行级安全保证每人只能看到自己的数据，部署在 GitHub Pages，所以**完全免费、无广告、无需下载**。

目前刚上线，欢迎各位试用并狠狠提意见（页面里有反馈渠道）。地址：https://craftr-x.github.io/fitnessWeb/
